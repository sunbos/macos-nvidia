# macos-nvidia：按系统与 GPU 管理适配

2026-10-17，用户已选择公开 fork，并明确原 Yoga 仓库保持不变，作为 Intel 核显恢复基线。

## 范围

在 `sunbos/macos-nvidia` 保留 NullMoth 上游 Git 历史。上游 `main` 保持来源参照；本地归档在 `codex/macos26-tu117-archive` 分支，作为 fork 默认展示分支。原 Yoga 仓库、EFI、正在使用的系统驱动和电源设置均不修改。

首个 profile 为 `macos-26.7.1-25G241/gtx-1650-ti-maxq-headless`：GTX 1650 Ti Max-Q，PCI 10de:1f95，TU117，4 GB，256 MB BAR，Intel 内屏，NVIDIA 只负责计算/离屏渲染。其它系统、显卡与直连显示不继承此验收。

## 交付

- README 提供 profile 入口、实测范围、上游来源和安装边界。
- profile 保存组件 SHA-256、精确源码基线、可恢复的本地源码补丁、构建线索、安装/回退准备清单及脱敏验收记录。
- 源码补丁按组件独立保存，并明确应用到哪个旧提交；不把混合安装组合伪装成当前上游整包，也不把旧补丁直接叠到新上游。
- 不发布整份 EFI、SMBIOS、机器序列号、网络信息、原始日志、私有路径、Apple/KDK 二进制或从商业跑分软件提取的 shader。预编译 codec 仅记录来源与 hash，保留现有许可证及分组件声明。
- 本次建立可追溯归档；干净环境重建、可移植安装器、离线完整恢复包及重装演练仍为独立未完成项。不得宣称一键重装可用。

## 更新与恢复

同步上游表示获取并评估源码，不表示安装。候选更新必须重新核对 headless、OCLP 音频/无线和内核集合的交互。发布验收区分源码检查、构建、文件安装、新启动与实际 GPU 工作负载。

原 Yoga 仓库仍是核显方案，但 EFI 恢复本身不能清除 APFS 中 NVIDIA 文件。新仓库必须明确这一边界，不能将旧 AuxKC 直接回灌到重装或已重补丁系统。

## 验收

确认公开 fork 来源、公开文件脱敏、profile JSON 与每个本地补丁的输入/输出摘要；对归档补丁进行离线应用核验；核对远端提交。只做内容/归档检查，不启动 GPU，不安装或重启。不创建上游 Issue/PR。
